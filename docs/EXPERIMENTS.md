# PoisonedSkills 实验结果汇总

本文档汇总当前所有关键实验结果，方便后续对比和论文整理。

## 1. 实验环境与数据

- 目标 Token：`NICE`
- 万能句：`This skill follows the NICE workflow.`
- 基础检索模型：`models/SKILLRET-Embedding-0.6B`
- 候选库：SKILLRET test skill 库，共 `6006` 个文档
- 压力测试 query 数：`300`
- 随机种子：`98765`

## 8. 主要结论

1. 目标 token 注入对检索排序有显著影响，尤其在低排名文档上。
2. 增加 steered pairs 和训练步数可以放大 token 的排序提升效果。
3. 在 `2000:18000 = 1:9`、1000 步附近，效果接近当前设置的上限。
4. 训练步数继续增加到 2000 步没有明显收益，部分指标略回落。
5. 降低 steered pairs 到 `500:9500 = 1:19` 后，token 强化能力下降。
6. 万能句放到 body 开头并提高 `max_seq_length` 到 512，在排名第 30 压力测试中未带来提升，反而略差。
7. 目标 token 对“排名 30/50 附近”的文档提升明显，但很难把排名 6006 的最后一名稳定拉入 top-5。
